SEIYU PARADISE PENGUIN MOD v1.0.0

Skate 3 Mobile players should install this mod from the Mod Store in the app.

Manual installation:
1. Open the Skate 3 Mobile launcher.
2. Open Mod Store, select Seiyu Paradise Penguin, then choose Import files.
3. Select base.obj first.
4. Select texture_diffuse.png second.
5. Start the game and open RB + Start > Mods > Playable Character.
6. Select Seiyu Paradise Penguin.

The original skater remains available. No Skate 3 retail game data is included.
