What to send

Character ZIPbase.obj plus texture_diffuse.png, with no retail game files.
Preview imageA clear PNG or JPG showing the character from the front and side, preferably standing on a board.
Credit and permissionYour creator name, profile link, and confirmation that the files may be redistributed in the public store.

Technical package

  • Name the model base.obj and the diffuse texture texture_diffuse.png.
  • Triangulate the OBJ and include UV coordinates and normals.
  • Keep the expanded model below 65,535 vertices for the native renderer.
  • Use Seiyu's package as the orientation, scale, and folder-layout reference.
  • Keep feet clearly separated and placed at the bottom of the model so automatic rig transfer can find the board contact points.
  • Test tricks, pushing, bails, emotes, the board, and both camera directions before submission.

The runtime transfers the live skater skeleton automatically. Characters with unusual bodies may need project-specific scale, foot, flipper, or hand tuning before publication.

Review process

1. SubmitOpen the GitHub form, complete every field, then attach your ZIP and preview.
2. Test and tuneThe character is checked for safe files, permissions, rendering, animation, board contact, and handheld performance.
3. Publish and creditApproved files receive exact size and SHA-256 records, creator credit, and a verified Mod Store listing.
Only submit work you created or have explicit permission to redistribute. Never upload a Skate 3 ISO, XEX, Title Update, DLC, extracted retail model, or other copyrighted game data.
Submissions are reviewed individually and publication is not guaranteed. Return to the Skate 3 Mobile Mod Store.
