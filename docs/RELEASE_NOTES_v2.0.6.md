# Skate 3 Mobile v2.0.6

The first player-ready Android release.

## Install

1. Download `Skate3-Mobile-Android.apk` below.
2. Install it and open Skate 3 Mobile.
3. Select an Xbox 360 Skate 3 ISO dumped from your own supported copy.
4. Leave the app open while it extracts and verifies the game locally.
5. Press **Play Skate 3**.

No computer or separate ISO extraction app is required. The APK does not
contain retail game assets, and your ISO is not uploaded.

## Included

- Native ARM64 recompilation and Vulkan rendering
- RG406V Performance and High-End Quality profiles
- Phone-only ISO extraction and exact game-file verification
- Automatic verified Title Update 3 setup
- Controller support
- Live **RB + Start > Mods > Playable Character** selection
- Original Skater selected by default
- Optional Seiyu Paradise Penguin import through Android's file picker

## Requirements

- Android 13 or newer
- 64-bit ARM processor
- Vulkan support
- Physical controller or built-in gamepad
- About 8 GiB free after the ISO is already available

The RG406V is the first verified device. Other phones and handhelds are
experimental, so please report results with the exact device and chipset.
